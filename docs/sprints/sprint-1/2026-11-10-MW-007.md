## O que cada um fez

**🧭 Marina (PO):** "Um controle de gastos que esquece tudo ao reiniciar não controla nada. A
MW-007 faz registrar, editar e excluir sobreviverem ao reinício, com o mesmo id, a mesma ordem e
os centavos exatos, sem mudar o front nem o contrato. Fechei a MW-006 como Entregue, criei a
MW-011 (uma fonte só para a seção do total) e levei os débitos do Rafa para o backlog."

**🛠️ Caio (Dev):** "Arquivo JSON local com `System.Text.Json`, sem pacote novo. A lista continua
em memória e cada mudança aceita grava o arquivo inteiro (temporário + `File.Move`, sob o mesmo
lock) antes de trocar a lista, então 400, 404 ou falha de gravação não mudam nada. Arquivo
ilegível impede a subida, com log em português, sem tocar no arquivo. Cada teste usa um
`TempDataFile` próprio."

**🔍 Bia (QA):** "Aprovado no head `f375617`. CI verde com 78 testes .NET (12 novos de
persistência) e web 92/92. 'Reiniciar' nos testes é subir um segundo host no mesmo arquivo; 20
POST em paralelo voltam todos. Conferi que os testes antigos só mudaram na montagem. Não
consegui reiniciar a API de verdade sem o SDK — vale o stakeholder testar."

**✍️ Leo (Tech Writer):** "README ganhou 'Onde ficam os dados' (local padrão, como trocar, como
começar do zero e os avisos da Bia). ADR 0014 substitui a 0002. `docs/api.md` explica a subida
com arquivo ilegível. Isso fecha o critério 12."
