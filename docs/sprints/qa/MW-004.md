## Observações (não bloqueiam)

- **Critério 7 pendente:** `docs/api.md` precisa do endpoint `GET /api/expenses/totals-by-category` com exemplo com gastos e sem gastos (`[]`). Tech Writer.
- **Formato do `total` no JSON:** como no total da MW-003, o número sai com a escala do `decimal` (ex.: `100.00`, `0.30`, mas pode sair `100` ou `58.4` dependendo dos valores informados). A tela formata corretamente; padronizar 2 casas é a MW-009, fora de escopo.
- **Código de categoria desconhecido no front:** se a API devolvesse um código fora da lista, o `categoryLabel` mostraria o código cru (ex.: `pets`), contrariando a regra de nunca mostrar o código. Hoje é inalcançável (a API valida na criação); fica registrado para quando existirem categorias personalizadas.
- O padrão carregando/erro/`reload()` agora se repete em três componentes; o Dev optou por não extrair nesta história (registrado em "Decisões do Dev"). Candidato a refatoração em PR próprio.
- Não houve teste manual com `curl` por falta do SDK .NET nesta sessão; a evidência da API é o CI no mesmo head.
